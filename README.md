# MockRouteRunner

听说有人苦校园跑久矣？

这是一个还在慢慢完善的 Android 路线模拟与步频测试项目。把自己的路线导进来，设置好距离、配速和扰动范围，就可以沿着路线运行，随时暂停，再从断点继续。路线和参数尽量放在一个界面里，方便反复调整和测试。

项目里也放了 StepDemo 和可选步频模块。StepDemo 用来直接观察消费者收到的步数事件，帮助分清“界面显示了一个数字”和“另一个 App 确实收到了数据”。

## 目前做到哪了

**悦跑世界已由使用者确认可用。** 这是当前的使用反馈；具体适用版本、设备和权限条件，仍需要更多人补充。步道乐跑还没有完成验证，暂时不写进已支持名单。

基础功能已经包括 GPX/JSON 导入、经纬度多点编辑、开放折线和闭环、暂停继续，以及断点保存。单条开放折线走到端点后原路折返，多条闭环则在共享路口切换。路线编辑支持新增、删除和调整点的顺序。

还没做完的部分也先写在这里：指定起终点的随机路网规划、必经打卡点和顺序约束仍待实现。当前输入一串经纬度点，不等于软件知道两点之间有没有围墙、建筑或可走的道路。

## 先用起来

安装包见仓库的 [Releases](https://github.com/SpillOverColors/MockRouteRunner/releases)。目前按测试版发布，安装前先看对应版本说明。旧版和新版可能有签名差异，遇到无法覆盖安装时，先保留路线文件和应用数据，不要直接卸载重来。

第一次使用，打开系统定位，给路线模拟器精确位置权限，再到开发者选项里选择这次安装的应用作为模拟位置应用。然后导入路线，检查坐标和长度，设置参数，点开始。请先停掉其他模拟定位工具，避免两个应用争用定位提供器。

当前界面里的配速用“秒/公里”填写，可在 **180–600 秒/公里（3:00–10:00/km）** 内自行设置最快和最慢值。步频上下限可在 **1–300 步/分钟** 内选择，总距离接受任意有限正数。下面列的是默认值和输入示例，不是固定要求：

| 参数 | 示例 | 说明 |
|---|---|---|
| 最快配速 | `390` | 6 分 30 秒/公里 |
| 最慢配速 | `470` | 7 分 50 秒/公里 |
| 总距离 | `5000` | 单位是米，不要求单圈也有这么长 |
| 位置扰动上限 | `0.3` | 单位是米，当前允许 0–0.5 |
| 步频范围 | `100`–`130` | 增强步频需要消费者接入模块 |

暂时离开时点“暂停并保存断点”，回来点“继续断点”。如果这次已经结束，就点“停止并清理”。暂停和停止的用途不同：正常停止会清除本次可继续的断点。

详细操作和常见问题写在 [两个软件使用教程](docs/两个软件使用教程.md)；想了解可选的改包流程，读 [APK 改包使用教程](docs/APK改包使用教程.md)。

## 路线怎么准备

经纬度采用 **WGS84，顺序为纬度、经度，也就是 `lat,lon`**。项目没有内置地图坐标转换，导入前要确认数据来源和坐标系。

`examples` 里有两类示例：

- `synthetic-square.gpx` 和 `synthetic-two-loops.json` 是合成路线，适合检查导入、闭环和多路线切换。
- [北大燕园约 5 km 示例](examples/pku_yanyuan_5km)依据公开地图中的相连道路、步道生成，先走约 2.5 km，再原路返回。目录内同时提供 `.gpx` 和同内容的 `.xml`，都可以作为 GPX 轨迹导入。

北大示例的原始几何长度约 5000 米，软件内部平滑后约 4977.2 米，运行总距离可以设为 5000 米。这份路线没有实地核查门禁、施工和当前通行情况，使用前仍需自己看一遍。

## 步频这一块怎么理解

基础路线模拟和可选步频增强是分开的。未接入模块的 App 不会因为你填了它的包名，就自动收到增强步频。做自检时，可以先打开带模块的 StepDemo，再在路线模拟器里把目标包名设为 `io.github.dsh.stepdemo`。

已有自有消费者实测记录：连续事件约 101–106 步/分钟；暂停后事件数不再增加，继续后恢复，停止后保持不变。这些记录来自 StepDemo，不直接代替其他 App 的事件级验证。

旧测试版恢复后的第一个读数会跨越暂停间隔，曾出现约 16 步/分钟的瞬时低值。新版改用事件时间戳和步数差，并标记边界样本；这部分新版改动还需要继续实机检查。遇到问题时，最好同时提供连续事件，而不是只截一个步频数字。

## 几个还需要留意的地方

定位使用 Android 标准模拟位置接口，系统会保留 mock 标记。其他 App 可能自行计算距离和速度，它们显示的配速不一定等于这里的设定值。

开放路线在端点做 180° 折返时，相邻两个定位点之间的直线距离会变短。因此，跨折返点的采样窗口可能低于速度下限；固定为 600/600 秒/公里时，闭环急弯的全样本速度界限也尚未完全满足。目前不能保证每一个样本都在 所设配速范围，参数框填对了也不会消除这个几何问题。

新图标版本已通过核心 104 项、断点 25 项、模块 40 项和协议 9 项离线测试，但这些测试不等于所有功能都已经在所有设备上跑过。版本说明会把已实测和待验证部分分开记录。

## 自己编译

完整构建入口见 [BUILDING.md](BUILDING.md)。主 App 使用原生 Java，通过本地 JDK 和 Android SDK 工具构建；推荐从 `build-release.ps1` 开始。部分辅助脚本仍有开发机默认路径，换电脑后需要检查配置。

源码不带签名私钥。自己编译会生成自己的调试签名，后续更新请保留那份密钥。可选改包流程还需要另外取得对应版本的 LSPatch，并按教程核对校验值和依赖。
